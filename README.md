# Projeto Uber — Dashboard v8

Esta versão não precisa de pasta local de ícones ou fontes.

## Dependências externas
- Fonte: Inter via Google Fonts
- Ícones: Lucide via CDN (`unpkg.com`)

## Estrutura mínima do repositório
```
projeto-uber/
└── index.html
```

## GitHub + Vercel
Basta subir o `index.html` na raiz do repositório.

O navegador baixa automaticamente a fonte e os ícones quando a página abre.
